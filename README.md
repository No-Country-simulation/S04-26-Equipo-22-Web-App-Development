# TalentCircle - Equipo 22 (S04-26)

## 🚀 Objetivo
Automatizar el monitoreo de comunidades y generar borradores de contenido (Newsletter, LinkedIn, Twitter) utilizando IA.

## 🛠️ Stack Tecnológico
* **Backend:** Java / Spring Boot
* **Base de Datos:** PostgreSQL
* **IA:** LLM (OpenAI API / LangChain4j)
* **Frontend:** React / JavaScript
